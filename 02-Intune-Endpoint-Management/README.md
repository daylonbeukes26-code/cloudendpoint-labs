# Microsoft Intune Endpoint Management

# Overview

In this project I used Microsoft Intune to worked with device compliance, Windows security settings, Windows Update and Microsoft Defender to get a better understanding of how endpoint policies can be managed from Intune.

# What I Did

- Created a Windows device compliance policy
- Required BitLocker, Secure Boot and Code Integrity
- Created a Windows configuration profile using the Settings Catalog
- Configured security settings including Windows Defender Firewall and Microsoft Defender SmartScreen
- Configured a 15-minute(900s) machine inactivity limit
- Configured a minimum password length of 12
- Created and configured a Windows Update ring
- Created a Microsoft Defender Antivirus policy
- Configured Microsoft Defender security settings
- Created an Attack Surface Reduction policy

# Device Compliance

I created a compliance policy for Windows 10 and later devices. The policy included requirements for BitLocker, Secure Boot and Code Integrity.

# Windows Security Configuration

I used the Intune Settings Catalog to configure Windows security settings including firewall, SmartScreen, password and inactivity settings.

# Windows Update Management

I created a Windows Update ring to practise controlling how Windows updates are delivered and managed through Intune.

# Microsoft Defender

I created a Microsoft Defender Antivirus policy and configured security settings such as real-time behavior monitoring and cloud protection.

I also created an Attack Surface Reduction policy to practise managing additional endpoint security controls through Intune.
